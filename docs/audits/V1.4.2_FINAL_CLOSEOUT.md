### Pre-existing CI failures (not introduced by this PR)

1. **Test coverage (41.0% < 45%):** The 45% threshold was set aspirationally. Actual coverage on main is 40.9%. This PR adds one regression test (`TestPollerQdrantDisabledNoPanic`) but doesn't move the needle on the ratio. Fix: either lower the threshold to 40% or add tests in a dedicated `chore/test-coverage` PR.

2. **Conformance (Docker health timeouts):** The conformance suite provisions real Docker containers and checks health. GitHub Actions runners don't reliably support Docker-in-Docker health checks within the timeout window. 21 of 24 runtime checks time out. This is an infrastructure issue, not a code issue. The suite passes locally on a machine with Docker.
