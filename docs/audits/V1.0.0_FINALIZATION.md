## Release pipeline fixes

The v1.0.0 release pipeline had 5 independent failures, all pre-existing
(v0.3.0-alpha release also failed). Fixed in order:

1. **Lint findings** (PR #94) — unchecked `io.Copy` and `json.Encode`
   in query handler and test
2. **Dockerignore + sbom-action SHA** (PR #96) — `.dockerignore` excluded
   `conformance/` (imported by main.go); sbom-action pinned to
   nonexistent commit SHA
3. **Syft --select-catalogers** (PR #97) — syft v1.20.0 changed CLI
   syntax, bare cataloger names no longer accepted
4. **Debian package build** (PR #98) — redundant `mv` where source and
   destination were the same path
5. **Debian package upload** (PR #101) — missing `actions/checkout` step,
   `gh` CLI had no repository context

### Positive findings

- Constant-time auth comparison throughout
- Request body size limits on all mutating endpoints
- Parameterized SQL everywhere
- XSS prevention in SPA
- Secrets never logged
- No shell execution from user input
- Container ports bound to loopback by default

## Decision point

audit identified real findings but none are exploitable without admin
credentials (the shared-secret auth model is documented in SECURITY.md
and LIMITATIONS.md as the architectural boundary).

**Recommended next steps:**

1. v1.0.1 security patch — address H1/H3/H4/M1/M4/M5
2. Operator/developer documentation — DOC-FINAL-03/04
